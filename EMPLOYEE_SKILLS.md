## Установка и личные ключи

Пример установки:

```bash
hermes skills install webdelo/seo-hermes-skills/skills/research/xmlriver-semantics
```

Для другого навыка замените `xmlriver-semantics` на его имя из таблицы. После установки напишите Hermes: «Загрузи навык xmlriver-semantics» (или имя выбранного навыка).

Установите выбранный навык командой из его README, затем попросите Hermes его загрузить. При первом открытии навыков XMLRiver, Topvisor и Ahrefs отсутствующие обязательные значения запрашиваются защищённой формой Hermes. API-ключ и пользовательский ID выдаёт владелец команды лично. Не присылайте их в обычный чат и не сохраняйте в папку навыка.

В интерфейсе без защищённого ввода настройку выполнить через локальный CLI Hermes. При пропуске настройки API-блокируется. Наличие ключа не разрешает расходовать баланс: перед запросом нужен согласованный предел. Объявленные переменные Hermes может передавать в удалённый terminal backend; используйте локальную доверенную среду либо согласуйте такую передачу.

Title, Description, проверка источников, сид-фразы и браузерная видимость ИИ не требуют общего API-ключа. Для внешнего кластеризатора сначала выбрать сервис: готового клиента нет. SEO-аудит имеет опциональные источники; без них выдаёт только проверенный охват.

## Известные ограничения

- XMLRiver собирает кандидатов Wordstat/подсказок. Существующий history-режим не является точной операторной частотностью; флаг --frequency не использовать.
- Браузерная видимость ИИ требует рабочего browser-инструмента; пакет не устанавливает браузер и аккаунты.
- Проверка ссылок источников не заменяет содержательную проверку фактов.
- Тесты скриптов не подтверждают доступность и тарифы реальных API.
- Независимый review остаётся отдельным действием рецензента; объединённый навык не создаёт иллюзию независимой проверки.

Публичный пакет содержит методики и код, но не ключи, клиентские отчёты или историю диалогов. Существующие навыки репозитория не изменены.
