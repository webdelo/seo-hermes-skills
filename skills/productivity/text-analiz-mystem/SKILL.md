# Text Analiz MyStem

Лемматизируй русский текст локальным MyStem, очищай его от стоп-слов и выдавай проверенный частотный отчёт. Скрипт анализа находится в `scripts/count_mystem_full_stats.py`; бинарный файл MyStem пользователь получает отдельно по лицензии Yandex.

## Когда использовать

- Пользователь просит частотный анализ, академическую тошноту или n-граммы русского текста через MyStem.
- Нужно посчитать заданные ключевые слова по леммам.
- Не использовать для генерации или редактирования текста.

## Предварительные условия

- Есть UTF-8 исходный текст, список стоп-слов и исполняемый MyStem для текущей ОС.
- Перед запуском прочитай `README.md` для актуального размещения файлов и вручную проверь наличие MyStem.
- Не добавляй бинарный MyStem в публичный Git-репозиторий: он распространяется по отдельной лицензии Yandex.

## Порядок работы

1. Положи исходный текст в `input.txt` без переписывания его содержания. Критерий: файл содержит весь текст пользователя в UTF-8.
2. Через `terminal` запусти `./mystem input.txt output.txt -d -l`. Критерий: создан непустой `output.txt` с леммами в фигурных скобках.
3. Через `terminal` запусти `python3 scripts/count_mystem_full_stats.py output.txt input.txt 'assets/Stop Words.txt' report/full_mystem_report.txt --cleaned-output report/output_cleaned_no_stop.txt --top 30`, скорректировав относительные пути для рабочей папки. Критерий: скрипт завершается с кодом 0.
4. Если приложен список ключей, передай `--keywords-file <путь>`. Критерий: в отчёте есть раздел «Заданные ключевые слова»; ключи были лемматизированы скриптом.
5. Через `read_file` проверь общую статистику и наличие ровно 30 строк в каждом списке: слов, биграмм и триграмм. Критерий: каждая строка имеет вид `элемент — частотность (процент%)`.
6. Верни пользователю отчёт как файл и кратко назови основные метрики. Критерий: путь к готовому отчёту доступен пользователю.

## Метрики

- Символы: с пробелами и без пробелов.
- Слова: количество лемматизированных токенов, удалённых стоп-слов и токенов после очистки.
- Частотность: 30 слов, биграмм и триграмм; процент считается внутри соответствующего списка всех вхождений.
- Академическая тошнота: `sqrt(sum(freq²)) * 100 / sum(freq)` по словам после удаления стоп-слов.

## Проверка

Успех означает, что MyStem и скрипт завершились без ошибки, `report/full_mystem_report.txt` существует и содержит общую статистику, академическую тошноту и три списка по 30 позиций.
