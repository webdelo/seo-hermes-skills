# Text Analiz MyStem

Локальная утилита для лемматизации русскоязычного текста через Yandex MyStem и частотного анализа после удаления стоп-слов.

## Что делает

- запускает MyStem с параметрами `-d -l`;
- получает леммы из вывода в фигурных скобках;
- удаляет одиночные стоп-слова и стоп-фразы;
- считает топ-30 слов, биграмм и триграмм;
- для каждой позиции показывает частотность и её долю среди всех однотипных вхождений;
- считает символы, токены, удалённые стоп-слова, уникальные n-граммы и академическую тошноту;
- при наличии списка ключевых фраз один раз лемматизирует его и считает точные вхождения в лемматизированном тексте.

Академическая тошнота рассчитывается по очищенным словам:

`√Σ(частота_слова²) × 100 / Σ(частот_всех_слов)`.

## Состав

- `scripts/count_mystem_full_stats.py` — скрипт анализа;
- `assets/Stop Words.txt` — стартовый список стоп-слов;
- `SKILL.md` — процедура для Hermes.

Бинарный файл MyStem не хранится в репозитории: это отдельный продукт Yandex с собственной лицензией. Скачайте подходящую для вашей ОС версию с официальной страницы MyStem и поместите исполняемый файл рядом с входными файлами. Не добавляйте его в коммит.

## Ручной запуск

1. Создайте рабочую папку и положите в неё:
   - бинарный файл `mystem`;
   - исходный текст `input.txt` в UTF-8;
   - `Stop Words.txt`;
   - скрипт `count_mystem_full_stats.py`.
2. В терминале из этой папки выполните:

```bash
./mystem input.txt output.txt -d -l
python3 count_mystem_full_stats.py \
  output.txt input.txt 'Stop Words.txt' report/full_mystem_report.txt \
  --cleaned-output report/output_cleaned_no_stop.txt
```

3. Откройте `report/full_mystem_report.txt`.

По умолчанию в каждом списке выводится 30 строк. Чтобы изменить число строк, добавьте, например, `--top 50`.

### Подсчёт заданных ключевых слов

Создайте `keywords.txt`: одна фраза или слово на строку. Затем выполните:

```bash
./mystem input.txt output.txt -d -l
python3 count_mystem_full_stats.py \
  output.txt input.txt 'Stop Words.txt' report/full_mystem_report.txt \
  --keywords-file keywords.txt \
  --cleaned-output report/output_cleaned_no_stop.txt
```

Скрипт сам лемматизирует `keywords.txt` один раз и добавит раздел «Заданные ключевые слова» в отчёт.

## Работа через Hermes

1. Дайте Hermes исходный текст файлом или вставьте его в чат.
2. Попросите: «Положи этот текст в `input.txt` и выполни частотный анализ MyStem». При необходимости приложите `keywords.txt` и попросите учесть заданные ключи.
3. Hermes должен запустить MyStem с `-d -l`, затем скрипт анализа, проверить отчёт и вернуть его файлом.

Пример запроса:

> Проанализируй приложенный текст через MyStem: используй `Stop Words.txt`, выведи топ-30 слов, биграмм и триграмм с частотностью и процентом, общую статистику и академическую тошноту. Сохрани отчёт файлом.

## Требования

- Python 3.9+;
- MyStem для вашей ОС и архитектуры;
- текстовые файлы в UTF-8.
