# Происхождение

Навык создан по проверенному рабочему процессу сравнения одного основного сайта с кластеризованными списками точных URL конкурентов через Ahrefs API v3 и DataForSEO Backlinks API.

В пакет включены только обобщённая методика, stdlib-скрипт и синтетические тесты. Реальные ключи, клиентские URL, ответы API, отчёты и история переписки не включены. Существующий `backlink-audit` не изменялся.

Новая лицензия автоматически не назначается; права на исходные материалы сохраняются за их правообладателями.
