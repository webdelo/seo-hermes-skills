# Топвизор: анализ позиций

Установка:

```bash
hermes skills install webdelo/seo-hermes-skills/skills/research/topvisor-analysis
```

После установки попросите Hermes: «Загрузи навык topvisor-analysis».
Появится защищённый запрос недостающих обязательных доступов. Значения выдаёт владелец команды лично.

Методика: `SKILL.md`. Связанные справочники и скрипты поставляются внутри этой папки.

Python 3.11+. Дополнительные источники, браузер и платные запросы включаются только после проверки доступности и согласования. Тесты не доказывают доступ к платному API.
