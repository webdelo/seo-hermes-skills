# Происхождение

Методика разработана Spara Daniil совместно с Hermes Agent на основе практических CJM-исследований для мониторинга видимости проектов в ответах ИИ.

Публичный навык содержит только универсальный процесс. Клиентские отчёты, исходная семантика, переписки, ключи и закрытые данные не включены.
