# CJM и промты для видимости в ИИ

Установка:

```bash
hermes skills install webdelo/seo-hermes-skills/skills/research/cjm-ai-prompts
```

После установки попросите Hermes: «Загрузи навык cjm-ai-prompts».

Навык строит CJM по пользовательским ситуациям и интентам, отбирает только пригодные для мониторинга AI-промты и завершает отчёт таблицей «Стартовый набор». Обязательный API-ключ не требуется.

Для фактического прогона утверждённых промтов используйте отдельный навык `ai-visibility`.
