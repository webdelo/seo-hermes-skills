# Локальные SEO-страницы Webdelo

Установка:

```bash
hermes skills install webdelo/seo-hermes-skills/skills/research/webdelo-local-seo-pages
```

После установки попросите Hermes: «Загрузи навык webdelo-local-seo-pages».

Навык использует свежий экспорт страницы Webdelo ID 100 как канонический шаблон, сохраняет `template-ref` 8/9/10/11 и проверяет классы отступов `!pb-22` и `!pt-22`.

Доступы к Webdelo Page API, Google Ads Keyword Planner и XMLRiver настраиваются отдельно в связанных навыках. Секреты в этот репозиторий не входят.
