# Извлечение и анализ текста страницы

Установка:

```bash
hermes skills install webdelo/seo-hermes-skills/skills/research/webpage-text-analysis
```

После установки попросите Hermes: «Загрузи навык webpage-text-analysis и проанализируй URL».

Навык получает HTML прямым HTTP-запросом, начинает извлечение с `//*[self::h1 or self::h2 or self::h3]`, предпочитает первый `h1` и останавливается перед related articles, рекомендациями или комментариями. Извлекаются абзацы, заголовки, списки, простые текстовые `div`, цитаты и таблицы. `alt` изображений и метаданные видео/аудио не извлекаются.

Требования: Python 3.11+ и `lxml`. Браузерная автоматизация не используется.
