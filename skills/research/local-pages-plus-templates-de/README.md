# Локальные страницы Webdelo.de и Templates

Навык `local-pages-plus-templates-de` выравнивает RU/EN локальных IT-страниц по согласованному немецкому макету: порядок блоков, отступы, ссылки на Templates и HTML-обёртки. Он не заменяет IT-страницы SEO-макетом и не запускает массовую миграцию без списка страниц.

## Доступ

Нужен отдельный секрет Webdelo Page API. Получите его у администратора и подключите как `WEBDELO_PAGES_SECRET` через защищённую конфигурацию активного профиля Hermes. Не вставляйте ключ в чат, JSON страницы, этот каталог или Git. Для подписанных запросов используется соседний навык `webdelo-pages-api`.

## Использование

Укажите номер страницы, эталонный номер/локаль и разрешённые локали изменения. Например: «Исправь RU/EN записи 89 по DE этой же записи; немецкую версию и метаданные сохрани; обнови только webdelo.de».

Навык требует свежую резервную копию, точечный PUT по block_id, явную карту статусов только webdelo.de и повторное чтение. Публичный HTML проверяется HTML5-парсером, включая порядок, классы и вложенность секций. Это не проверка скриншотами.

Если локализованный общий шаблон отсутствует, возможен документированный локальный HTML-fallback в той же позиции. Сам общий шаблон без отдельного разрешения не меняется. Fallback не получает последующих обновлений общего шаблона — его нужно перепроверять при следующей миграции.

В репозиторий включены только инструкции. Экспорты страниц, рабочие HTML, подписанные запросы и секреты сюда не входят.
