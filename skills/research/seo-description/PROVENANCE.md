# Происхождение

Адаптировано из локальных навыков: `seo-description`, `meta-description-writer`, `meta-description-critic`.
Методики перенесены для сотрудников; персональная оркестрация заменена проверкой результата. Ключи, проектные выгрузки и переписки не включены.
Новая лицензия автоматически не назначается; права на исходные материалы сохраняются за их правообладателями.
